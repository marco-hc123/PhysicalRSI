# 上传范围及资料来源

原始仓库版本从实验归档目录整理。2026-11-02 补充核对了实验室归档与本地已保存的历史材料；没有把整个工作区直接上传，也没有连接旧云主机。

包含：实验使用的上游源代码、冻结集成代码、历史服务器脚本、GPT 补测原始请求/响应、候选源码、逐回合结果、选择记录、历史正式任务和计时结果，以及相关核验文件。

不包含：API 密钥、密码、SSH 私钥、真实 runtime.json、完整模型权重、已安装虚拟环境、CPU 门禁隔离环境的系统库副本、全部逐帧观测与重复的大型执行对象。原件仍保留在服务器。选定结果和失败记录一起保留，上传不是重新抽样实验。

`provenance/SOURCES.csv` 对每个整理文件列出原服务器路径、原字节 SHA256、上传字节 SHA256、大小和是否脱敏。因敏感字段而脱敏的内容单列；不修改成功率、Score、Token 和原始实验身份字段。

`provenance/omitted.json` 记录受大小、重复内容或范围限制未加入的文件。该清单不是所有服务器文件的穷举；仓库不宣称完整镜像。上游演示视频与本次实验视频也不能混为新实验结果。

原始出处保留绝对路径，所以历史报告中的某些本机链接仅在原服务器有效；在 GitHub 阅读时请使用根 README 的仓库内导航和相应 CSV/JSON。

汇报材料另加入用户指定的当前 PPT，位于 `reports/presentations/`。其余代码与实验资料从服务器整理。
