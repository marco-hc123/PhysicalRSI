# 提示词、调度与 CPU 机制证据

`current/` 为 90b322a 阶段的静态提示词/调用机制审计，包含协议、字段、文本估算与源码验证。静态 tokenizer 估算不是服务商实际 usage；图像、聊天模板与服务商编码会造成差异。

`legacy_3c8cf7f/` 是更早版本的辅助实验：28 组调度配置、6,922 环境 chunk；512 个 CPU 代理控制回合；22 项计量工具检查与 72 行理论摊销情景。它们不是当前原生机器人复现成绩，也不属于新增实验。

CPU 控制对照中逐步反馈与本地闭环各 128/128、每四步反馈 110/128、开环 50/128。控制器、扰动和成功条件是合成的，不证明 LLM 已自动学会这些技能。fixture 中人工 Token 不加入真实 API 总账。

脚本保留来源与历史参数，仅用于检查机制；不要把旧脚本、当前接口及冻结原生数据混成一个代码版本。完整解释见 [研究总览](../../docs/RESEARCH_OVERVIEW_ZH.md)。
