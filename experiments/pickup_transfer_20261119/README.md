# 三模块迁移到 general_pickup

这项实验单独检验人工接入三个模块能否改善普通抓取。策略使用多视角 RGB-D 估计指定物体的位置，在闭爪前检查并纠正到位误差，在闭爪和抬升阶段保留图像用于事后判读。每回合最多 200 个动作步，原生评分以指定物体抬高超过 10 厘米作为成功条件。

| 布局与用途 | 历史策略 | 迁移策略 | 配对变化 |
|---|---:|---:|---|
| 3 个已有开发布局，接入验收 | 2/3 | 0/3 | 2 个由成功变为失败 |
| 20 个已有正式布局，冻结后复测 | 1/20，均分 5 | 0/20，均分 0 | 0 个改善，1 个由成功变为失败 |

旧策略复用已有终局，本批只运行迁移策略。20 个正式布局与此前抓取独立验收逐个匹配，所以这次回答的是同布局复测问题。两阶段均拿到了全部计划终局。[开发数据](development-scores.csv) · [正式数据](formal-scores.csv)

正式复测中，8 回合走完程序，4 回合在闭爪前未到位，3 回合的接近规划被拒绝，3 回合未检出目标，2 回合的抬升规划被拒绝。40 个动作窗口中，18 个具备盲法图像复核条件，22 个未执行到相应动作；这些窗口不能用来计算实际抓住物体的次数。

| 冻结源码 | 作用 |
|---|---|
| [migrated_policy_v2.py](code/migrated_policy_v2.py) | 把观测、接近、闭爪和抬升串成抓取策略 |
| [pickup_modules.py](code/pickup_modules.py) | 多视角目标点估计、接触目标与闭爪前纠正 |
| [holding_windows.py](code/holding_windows.py) | 将诊断图像绑定到实际发生的动作阶段 |

三个文件均按实验冻结哈希核对。运行还依赖实验环境中的感知权重、运动学函数、通信适配和仿真资产。CSV 可在仓库内独立复算。[来源与哈希](../../provenance/november-evidence-20261120.json) · [复现条件](../../docs/REPRODUCE.md)
