## 得到的结论

- 普通分类：换用 GPT 后平均总 Token 为 11,661.6，较历史千问 12,604.0 变化 -7.48%；成功数 1/5 → 1/5，平均 Score 32.0 → 47.0。
  输入 11,546.0 → 11,545.0；输出 1,058.0 → 116.6；缓存命中输入 4,147.2 → 0.0。缓存是 input 的子集，不额外加进 total。
  本组输入用量接近，总 Token 的下降主要来自输出缩短；去缓存指标的变化还受缓存命中量影响。
  供应商 usage 中报告的平均 reasoning Token：千问 955.2 → GPT 0.0；已包含在 output 中。本轮 GPT 返回该字段为 0，仅按账目记录，不据此判断模型内部是否推理。
- 语言分类：换用 GPT 后平均总 Token 为 11,719.4，较历史千问 12,332.4 变化 -4.97%；成功数 1/5 → 2/5，平均 Score 30.0 → 46.0。
  输入 11,588.8 → 11,587.8；输出 743.6 → 131.6；缓存命中输入 0.0 → 0.0。缓存是 input 的子集，不额外加进 total。
  本组输入用量接近，总 Token 的下降主要来自输出缩短；去缓存指标的变化还受缓存命中量影响。
  供应商 usage 中报告的平均 reasoning Token：千问 627.0 → GPT 0.0；已包含在 output 中。本轮 GPT 返回该字段为 0，仅按账目记录，不据此判断模型内部是否推理。
- 本轮 10 个正式回合共 10 次逻辑规划、10 次实际 HTTP；所有请求均纳入统计。后续本地 code/VLA 执行不计入语言 API Token。
- 此补测隔离了技能目录变化，但高层供应商、模型及推理配置一起更换。因此不能将差异进一步归结为某个分词器或某项推理机制的独立贡献。

## 条件与完整性

- 两任务各布局 5–9，seed=0，每布局正式执行一次；控制上限 1100 步，控制间隔 0.04 s。保留成功和失败，不重跑挑选结果。
- 同一冻结技能目录、技能实现与本地 VLA 权重路径；目录未精简。活动源码和技能描述文件已核对原始哈希。
- GPT 使用 reasoning_effort=medium、max_completion_tokens=16000、标准服务层。为兼容接口移除千问的 enable_thinking 和旧请求的 temperature；推理 Token 若已在 output 内，不重复相加。
- 配对请求核对：10/10 对技能目录一致（仅模型、端点和结果路径变化）；10/10 对请求文本完全一致；0/10 对初始相机 PNG 完全一致。相机输入并非逐像素相同，因此未构成完全相同输入的对照。
- 仿真在服务器（L20）。服务器直连 OpenAI 超时，因此由本机 OpenAI 客户端通过加密 SSH 通道与仿真通信；OpenAI 密钥仅保存在本次客户端进程内存。
- HTTP 耗时包括 SSH 传输和本机客户端，不据此宣称 GPT 比千问接口更快。去缓存指标=input−cached input+output，未另跑关闭缓存条件。
