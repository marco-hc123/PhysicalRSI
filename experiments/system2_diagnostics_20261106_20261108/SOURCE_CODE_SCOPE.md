# 源码与原件边界

`stages/` 保留实验室原结果组名、运行目录名和层次；代码和小型协议/结果保持原始字节。运行、缓存和逐回合目录中的重复文本通过无损索引追溯。原脚本仍保留当时的环境、路径与服务假设，不是本仓库的一键复现实验入口。

`candidates` 目录名不意味着全部代码由模型自主生成。阶段32的门控副本、38–40的运输/观察/拒绝契约对照属于人工诊断；33、42、43的生成候选应与各自保存请求/响应和冻结协议一起阅读。发布技能参照、手工适配器、分析工具和生成策略不混算自主改进。

历史 `AGENTS.md` / `CLAUDE.md` 改为 `.snapshot.txt` 文件名，字节不变。它们是证据，不因归档而成为当前仓库的操作指令。评分、成本、失败和中断的统计解释见仓库最新结果页及本周报告。
