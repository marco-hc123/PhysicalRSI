保留原始 CSV/JSON 和 SVG/PNG，不将图像当作唯一数据来源。SVG、Mermaid 和 draw.io 等格式可编辑；统计图对应历史协议与分母，不自动更新为 GPT 补测结果。部分完全相同的表复用仓库已有位置，因此清单中的目标不一定全在本目录。
