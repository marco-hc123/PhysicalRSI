统计口径与术语

1. Task / Layout / Episode / Candidate
Task是任务类型，如classify_objects分类和general_pickup抓取。Layout是某一次物体配置。Episode是一个策略在一个布局上的一次原生执行。Candidate是一次模型生成所得的代码候选。
3候选×5布局=15次执行，但只有3个生成样本和5个不同布局。相同布局反复执行不是15个独立场景。

2. Parent / Baseline / Augmented
Parent是本次选择要超越的起点，可能是pi05，也可能是冻结代码。Baseline只表示某一实验的对照，不能默认所有批次都相同。Augmented通常指增加执行或失败反馈的信息条件，不是另一个预训练模型。
11月7日fixed_parent是代码父策略；11月8日general_pickup起点是研究中编写的单次抓取代码，pi05另列能力参照。

3. System 1 / System 2
System1在当前任务中选择或执行已有技能。System2根据证据提出新技能代码，验证后决定是否替换父策略。人工改接口或目标的结果不能自动记为System2自主学习。保存代码的执行无需每步调用语言模型。

4. Native / API-only / Offline
Native表示真实进入冻结RoboDojo与Isaac Sim的RGB和物理闭环，并由原生评估器给分。
API-only只生成或检查模型响应。Offline包括CPU契约夹具、保存状态上的规划求解、合成输入的权重推理。三类结果分开统计。

5. Frozen protocol
冻结的是本次对照的任务布局、候选或生成条件、模型与推理设置、可用接口、执行版本、评分、预算、选择规则及统计口径。
冻结后发现实现错误，可以保留旧证据并新建更正实验；不能不留记录地修改正在评分的源码，再把两版结果放成同一组。
本周并非整个星期都使用完全相同的执行器。多个批次逐项修正，每个匹配对照内的变量才具有解释意义。

6. Admission / Rejection / Runtime error
Admission是源码准入。未准入候选没有物理得分，应填未知或不适用，不能填0。
规划明确拒绝可能表示零动作发生。候选应收到的结构化字典和真正收到的异常必须分开。批次40更正了本研究适配层的不一致。
Runtime error有时来自任务成功触发结束后的清理关闭；须结合原生success、动作计数和日志时序，不能只看error一词。

7. Native score / Success / Physical proxy
本包统一绘图分数0–100，原始单回合明细常为0–1。
classify_objects阶段评分15、40、100不累加；不是已处理物体的百分比。它检查类别完整入筐、篮筐纯度、物体高度、张爪等。完整success另外检查任务完成和归位等条件。
general_pickup的公开任务要求把指定对象抬升10cm，原生成功表示满足该任务评价；不表示完成分类或持久搬运。
抬升、共动、稳定入筐等事后物理代理帮助定位机制，不能替代原生评分。代理阈值、对象选择和异常清理情况见批次41。
完整成功条件、阶段得分和终态截图可能不同。早先获得的阶段分不能仅凭最后一帧推定持续满足。

8. Development / Heldout
Development用于选择或调参。Heldout在策略选择冻结后才生成/使用。已经用来分析和修改策略的布局不再是下一轮独立测试集。
11月7、8日的新布局来自公开任务配置的研究采样，未证明与官方完整benchmark的分布等价。
多个选择视图最终都保留同一父策略时，可以复用同一组独立执行，但不能把复用当成多次独立实验。

9. Token 与成本
input+output=total。cached input和cache-write属于input内部项目；reasoning若已经包含在output中，不再重复相加。
账目分别标出技能选择、System2生成和预检请求。原生执行API为0并不表示获取技能、仿真或GPU推理没有成本。
历史费用按保存的usage和冻结估算公式重算，不是实际账单核对；供应方实扣金额仍未知。预算预留也不是实扣。
目录精简约80%的输入Token下降是更早的PhysicalRSI自身消融，不是本周的新结果或两个项目的节省比例。

10. Time
物理仿真时间、原生动作步数、规划/API等待、cohort墙钟、完整部署研究时间是不同量。候选返回后还可能保持到任务步数终止。
跨主机UTC时间不能直接相减作精确耗时；采用同进程单调时钟。缺少项目A同口径完整墙钟，因此不报告跨项目加速倍数。

11. Evidence / Audit
本包保留可离线理解的报告、重算数据和代表视频，不是原始全量备份。完整环境、权重、逐帧观测和所有视频仍在服务器。
原报告的旧解释保留但需结合批次40更正。证据哈希一致证明内容一致，不自动证明科学解释正确。
发现归档省略空锁文件时，按原packager规则说明；不补造锁文件，也不把它算成评分或视频缺失。
